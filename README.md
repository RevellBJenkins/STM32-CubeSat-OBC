# STM32 CubeSat Onboard Computer

An STM32-based CubeSat onboard computer (OBC) prototype developed to explore embedded firmware, spacecraft subsystem monitoring, and system integration.

## Project Status

In development.

## Initial Development

- Temperature monitoring
- IMU integration
- Power monitoring
- Telemetry and data logging
- Fault detection and recovery

## Development Platform

- Microcontroller: STM32
- Programming language: C
- Development environment: STM32CubeIDE
